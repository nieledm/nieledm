## 🚀 Projetos & Soluções em Destaque

### 🪟 Infraestrutura Windows & Gestão de Domínio
* **Administração de Active Directory & GPO:** Gestão de Controladores de Domínio, políticas de grupo (GPOs) para padronização de estações, distribuição automatizada de licenças/softwares de rede e controle de acesso via Access-Based Enumeration (ABE) em compartilhamentos SMB/CIFS.
* **Publicação de Aplicações via RDS/RemoteApp:** Configuração e disponibilização de softwares científicos e corporativos licenciados (ex: ChemDraw) em servidores Windows Server via RemoteApp para uso simultâneo e seguro de usuários da rede.
* **Integração Híbrida Linux + AD:** Autenticação centralizada de serviços web (FastAPI, Wiki.js) e instâncias Linux via LDAP/SSSD integrados ao Active Directory.

### 🧪 Softwares & Soluções Web Internas
* **Sistema de Agendamento:** Aplicação web para reserva e gestão de recursos/laboratórios em Python (FastAPI, Uvicorn, PostgreSQL) com autenticação integrada ao Active Directory (LDAP).
* **Gestão de Quimioteca & Banco de Células (`celulas_cqmed`):** Portais de gestão com mapeamento visual 2D de tanques de nitrogênio líquido, importação dinâmica via Excel e rotas analíticas/clusters para biologia estrutural e química medicinal.
* **Central de Documentação Interna:** Implantação e gerenciamento do Wiki.js em ecossistema Docker para padronização de POPs e base de conhecimento.

### 🛡️ Virtualização, Redes & Automação
* **Cluster Virtualizado & Backups Enterprise:** Migração e consolidação de ambiente VMware ESXi para Proxmox VE com rotinas automatizadas de backup incremental e deduplicado via Proxmox Backup Server (PBS) em storage NAS QNAP.
* **Rede & Monitoramento Integrado:** Monitoramento ativo de ativos e sensores ambientais (IP PoE) via Zabbix, integrado a automações no n8n com alertas via WhatsApp e SMS (AT Commands via modem 4G).
* **Acesso Seguro & Proxy:** Arquitetura de publicação local/remota utilizando Nginx Proxy Manager, Cloudflare Tunnels e VPN Mesh (Tailscale/OpenVPN).
